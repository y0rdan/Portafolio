# Space Invaders

Pygame practice project. The game loop, sprites, and pixel-art assets follow Tech With Tim's tutorial [Pygame Tutorial - Creating Space Invaders](https://www.youtube.com/watch?v=Q-__8Xw9KTM). This folder is Yordan Borges's working copy. The downloaded tutorial zip and the unpacked tutorial directory have been removed.

Run it from this folder:

```bash
pip install pygame
python3 main.py
```
